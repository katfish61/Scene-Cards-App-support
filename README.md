# Scene Cards — Support

Scene Cards is a document-based app for film and TV professionals to organise, plan and track scenes.

## Getting Help

**To report a bug or ask a question — [open an issue](../../issues/new)**

You can also email: [scenecards67@gmail.com]

---

## Getting Started

1. **Launch the app** — tap New Wall to create a new Scene Cards document
2. **Import a script** — use Import Script PDF or FDX from the overflow menu (iOS) or File menu (macOS)
3. **Import a schedule** — use the Schedule mode and import a one-liner PDF, then import reports from camera , sound and continuity for each day
4. **Double Tap any scene card** to open the Inspector and add any folders, files, write notes, take a picture add images and videos to your scene reference section.

## Frequently Asked Questions

**My script imported but some scenes are missing**
Check that the file is a screenplay PDF, not a one-liner schedule. The importer looks for INT/EXT scene headings.

**My schedule imported but shows no data**
The schedule importer expects a one-liner PDF (breakdown sheet). Standard script PDFs often will not work here. Make sure the PDF has selectable text — scanned images are tricky to read sometimes.

**Where is my data stored?**
All data is stored locally inside the .scenecards document file. You can back it up, share it, or move it like any other file. Cloud Sync is available through an invitation and secure network only.

**The app is available on iPad — is there a Mac version?**
Yes — Scene Cards is a universal purchase. Download on Mac from the Mac App Store. Also available from Play Store on Android.
